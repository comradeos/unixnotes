# SSH по ключу

Короткий порядок действий:

1. Сгенерировать ключ: `ssh-keygen -t ed25519 -C "my-laptop"`
2. Оставить приватный ключ у себя: `~/.ssh/id_ed25519`
3. Перенести на сервер только публичный ключ: `~/.ssh/id_ed25519.pub`
4. Подключаться: `ssh user@server`

Файлы:

- `01_generate_key.md` - как создать ключ
- `02_copy_public_key.md` - что и куда переносить
- `03_connect.md` - как подключаться

Важно:

- `id_ed25519` - приватный ключ, никому не передавать
- `id_ed25519.pub` - публичный ключ, его добавляют на сервер
