# Как сгенерировать SSH-ключ

Команда:

```bash
ssh-keygen -t ed25519 -C "my-laptop"
```

Дальше:

- Нажмите `Enter`, чтобы сохранить в `~/.ssh/id_ed25519`
- При желании задайте `passphrase`

После этого появятся файлы:

```bash
~/.ssh/id_ed25519
~/.ssh/id_ed25519.pub
```

Смысл:

- `id_ed25519` - приватный ключ, хранится только у вас
- `id_ed25519.pub` - публичный ключ, его можно переносить на сервер
