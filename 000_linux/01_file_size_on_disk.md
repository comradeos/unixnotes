# Сколько места файл занимает на диске

Если нужно узнать, сколько места файл реально занимает на диске, используйте:

```bash
du -h file.txt
```

Пример вывода:

```text
4.0K    file.txt
```

Если нужен размер в байтах:

```bash
du -b file.txt
```

Если нужен логический размер файла, а не занятое место на диске:

```bash
ls -lh file.txt
```

Если нужно узнать общий размер папки:

```bash
du -sh mydir
```

Если нужен размер файлов и папок в текущем каталоге:

```bash
du -sh *
```

Если нужно посмотреть размер вложенных папок на один уровень:

```bash
du -h --max-depth=1 mydir
```

Более подробная информация:

```bash
stat file.txt
```

На что смотреть в `stat`:

- `Size` - размер содержимого файла
- `Blocks` - сколько блоков занято на диске

Коротко:

- `du` - сколько места занято на диске
- `ls` - обычный размер файла
- `stat` - подробная информация о размере и блоках
- `du -sh mydir` - общий размер папки
