# UART через USB в macOS

[Общая схема подключения и параметры UART](README.md).

## 1. Найти порт

Подключи USB–UART-адаптер и выполни:

```bash
ls /dev/cu.*
```

Ищи имя вида `/dev/cu.usbserial-...` или `/dev/cu.usbmodem...`.
Сравни список до и после подключения. Для исходящего подключения используй
вариант `/dev/cu.*`; парное устройство `/dev/tty.*` имеет другое назначение
при установлении соединения.

На этом Mac при проверке 27 октября 2026 года был найден порт:

```text
/dev/cu.usbserial-DK0DVD2D
```

Ниже используется это имя. На другом адаптере или после переподключения
найди актуальный путь. `/dev/ttyUSBX` — шаблон для Linux, в macOS он не подходит.

## 2. Быстро подключиться через встроенный screen

`screen` уже доступен на этом Mac в `/usr/bin/screen`. Проверка:

```bash
command -v screen
```

Подключение на скорости 115200:

```bash
screen /dev/cu.usbserial-DK0DVD2D 115200
```

Нажми `Enter`. Если плата выводит данные только при загрузке, перезапусти её
после открытия консоли. Скорость должна совпадать с настройками устройства.

### Выйти и освободить порт

Нажми последовательно:

1. `Ctrl+A`, затем отпусти клавиши.
2. Строчную `k`.
3. `y` для подтверждения.

`Ctrl+A`, затем `d` отсоединяет окно, но оставляет сессию и порт открытыми.
Чтобы вернуться и закрыть такую сессию:

```bash
screen -ls
screen -r ИДЕНТИФИКАТОР
```

Вместо `ИДЕНТИФИКАТОР` подставь значение из `screen -ls`, затем используй
обычную последовательность выхода. Если настроек screen недостаточно,
используй picocom с явно заданными параметрами ниже.

## 3. Установить picocom через Homebrew

Ошибка `sudo: picocom: command not found` означает, что команда не найдена.
На этом Mac Homebrew уже есть; проверить его можно так:

```bash
brew --version
```

Если на другом Mac Homebrew отсутствует, установи его по инструкции
с [официального сайта Homebrew](https://brew.sh/). После установки выполни
команды из блока `Next steps` для настройки `PATH` и открой новый Terminal.

Установка picocom:

```bash
brew install picocom
command -v picocom
picocom --help
```

Запускай `brew install` без `sudo`. Обычно подключение к порту тоже работает
без `sudo`.

## 4. Подключиться через picocom

Сначала закрой screen или другую программу, использующую порт.

```bash
picocom -b 115200 -d 8 -p 1 -y n -f n /dev/cu.usbserial-DK0DVD2D
```

Параметры: 115200 бит/с, 8 бит данных, 1 стоп-бит, без чётности и flow control.
Краткая команда с такими стандартными параметрами:

```bash
picocom -b 115200 /dev/cu.usbserial-DK0DVD2D
```

После подключения нажми `Enter`.

| Действие | Последовательность |
| --- | --- |
| Выйти | `Ctrl+A`, затем `Ctrl+X` |
| Справка | `Ctrl+A`, затем `Ctrl+H` |
| Показать параметры | `Ctrl+A`, затем `Ctrl+V` |
| Переключить локальное эхо | `Ctrl+A`, затем `Ctrl+C` |

Отпускай клавиши между сочетаниями. Обычный `Ctrl+C` передаётся устройству.
Локальное эхо помогает видеть ввод, если устройство само его не возвращает;
при двойных символах отключи локальное эхо.

### Записать лог

```bash
picocom -b 115200 -g uart-macos.log /dev/cu.usbserial-DK0DVD2D
```

Лог появится в текущем каталоге. Существующий файл дополняется.
Записываются принятые данные; при локальном эхо — также отправляемые.

## Если не работает

### Порт не появляется

Проверь USB-кабель: он должен поддерживать передачу данных. Попробуй другой
разъём или подключение без USB-хаба. Посмотреть USB-устройства:

```bash
system_profiler SPUSBDataType
```

Если адаптер виден в USB, но serial-порта нет, определи модель чипа
(например, FTDI, CP210x или CH34x). Для части моделей поддержка уже есть
в macOS; если требуется драйвер, бери совместимый с твоей версией macOS
на сайте производителя адаптера или чипа.

### Порт занят

Закрой другие serial-терминалы и Serial Monitor в IDE. Найти процесс:

```bash
lsof /dev/cu.usbserial-DK0DVD2D /dev/tty.usbserial-DK0DVD2D
```

Если список пуст, но ошибка остаётся, повтори проверку с `sudo lsof`.
Проверь `screen -ls`: отсоединённая сессия тоже может держать порт.

### Пустой экран или нечитаемые символы

- Нажми `Enter`; для загрузочных сообщений перезапусти плату.
- Проверь скорость и параметры UART по документации устройства.
- Проверь питание, общий GND и перекрёстное соединение TX ↔ RX.
- Для трёх проводов GND/TX/RX обычно требуется отключённый flow control (`-f n`).
- Если устройству нужен CR+LF, закрой сессию и запусти:

```bash
picocom -b 115200 --omap crcrlf /dev/cu.usbserial-DK0DVD2D
```
