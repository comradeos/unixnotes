# Отладочная UART-консоль через USB

Подключение к последовательной консоли платы, роутера или другого устройства
через USB–UART-адаптер либо встроенный USB serial.

## Инструкции

- [Linux](linux.md) — установка picocom, поиск порта, права доступа и подключение.
- [macOS](macos.md) — встроенный screen и установка picocom через Homebrew.

Команды выполняются на компьютере, к которому подключён USB-кабель.
Утилиты только открывают консоль: на самом устройстве UART должен быть включён,
а прошивка должна выводить сообщения или предоставлять командную оболочку.

## Подключение проводов

Если используешь отдельный USB–UART-адаптер с контактами TTL:

| Адаптер | Устройство |
| --- | --- |
| GND | GND |
| TX | RX |
| RX | TX |

Проверь распиновку и допустимый уровень сигналов по документации устройства:
например, UART 3,3 В требует совместимых уровней адаптера. TTL UART и RS-232
с разъёмом DB9 электрически различаются; для RS-232 нужен соответствующий адаптер.
Контакт VCC обычно оставляют неподключённым, если плата питается отдельно.
Подключай питание от адаптера только по схеме производителя.

Для устройства со встроенным USB serial достаточно USB-кабеля с передачей данных.

## Параметры консоли

Типичный пример для отладки — **115200, 8N1, без управления потоком**:

| Параметр | Значение |
| --- | --- |
| Скорость | 115200 бит/с |
| Биты данных | 8 |
| Чётность | None — отсутствует |
| Стоп-биты | 1 |
| Flow control | None — выключено |

Это пример, а не универсальные настройки. Используй параметры из документации
или конфигурации прошивки; иногда требуется 9600, 57600 или другая скорость.

## Имена портов

| Система | Примеры |
| --- | --- |
| Linux | `/dev/ttyUSB0`, `/dev/ttyACM0` |
| macOS | `/dev/cu.usbserial-DK0DVD2D`, `/dev/cu.usbmodem1101` |

`/dev/ttyUSBX` — шаблон из примеров для Linux. Вместо него нужно указать реальный
путь. Имя порта может измениться после переподключения адаптера.

Чтобы увидеть загрузочные сообщения, сначала открой консоль, затем перезапусти
целевое устройство, сохранив подключение USB–UART-адаптера к компьютеру.
