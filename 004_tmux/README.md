# tmux Vim Copy Mode

Короткий порядок действий:

1. Включить Vim-клавиши в `tmux`
2. Добавить бинды для выделения и копирования
3. Перезагрузить конфиг
4. Войти в Copy Mode: `Ctrl+b [`
5. Выделить текст: `v`
6. Скопировать: `y`
7. Вставить: `Ctrl+b ]`

Файлы:

- `01_setup.md` - настройка `~/.tmux.conf`
- `02_copy_mode.md` - вход в режим копирования и навигация
- `03_copy_paste.md` - выделение, копирование и вставка
- `04_useful_options.md` - полезные опции и минимальная конфигурация
- `05_windows.md` - как переименовывать окна

Важно:

- `setw -g mode-keys vi` включает Vim-клавиши в режиме копирования
- `set -g mouse on` включает мышь в `tmux`
- после изменения `~/.tmux.conf` конфиг нужно перечитать
