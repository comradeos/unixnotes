# Как копировать и вставлять

Порядок действий:

1. Войти в Copy Mode:

```text
Ctrl+b [
```

2. Начать выделение:

```text
v
```

3. Перемещаться клавишами:

```text
h j k l
```

Или использовать любые другие команды Vim.

4. Скопировать выделение:

```text
y
```

5. Вставить в активную панель:

```text
Ctrl+b ]
```

Быстрый пример:

```text
Ctrl+b [
v
y
Ctrl+b ]
```
