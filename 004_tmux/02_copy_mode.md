# Copy Mode и навигация

Войти в режим копирования:

```text
Ctrl+b [
```

После этого работают Vim-клавиши.

Основные перемещения:

- `h` - влево
- `j` - вниз
- `k` - вверх
- `l` - вправо
- `w` - следующее слово
- `b` - предыдущее слово
- `0` - начало строки
- `$` - конец строки
- `gg` - начало буфера
- `G` - конец буфера
- `Ctrl+u` - вверх на полстраницы
- `Ctrl+d` - вниз на полстраницы

Поиск:

- `/текст` - поиск
- `n` - следующее совпадение
- `N` - предыдущее совпадение
