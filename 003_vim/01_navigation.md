# Базовая навигация в Vim

Откройте файл:

```bash
vim TEST
```

Основные перемещения:

- `h` - влево
- `j` - вниз
- `k` - вверх
- `l` - вправо

Быстро по словам:

- `w` - к следующему слову
- `b` - назад к слову
- `e` - в конец слова

В начало и конец строки:

- `0` - начало строки
- `$` - конец строки

По всему файлу:

- `gg` - начало файла
- `G` - конец файла

Минимум, который полезно запомнить сразу:

```text
h j k l
w b e
0 $
gg G
```
