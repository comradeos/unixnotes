# Полезные настройки

Минимальные настройки для табов и отступов:

```vim
set tabstop=4
set shiftwidth=4
```

Смысл:

- `tabstop=4` - таб отображается как 4 пробела
- `shiftwidth=4` - автоотступы и сдвиги идут по 4 пробела

Обычно такие строки добавляют в:

```bash
~/.vimrc
```

Открыть конфиг:

```bash
vim ~/.vimrc
```
