# Макросы и текстовые объекты

Запись макроса:

1. Нажать `q`
2. Нажать букву регистра, например `a`
3. Выполнить нужные действия
4. Нажать `q` ещё раз для завершения

Запуск:

- `@a` - выполнить макрос из регистра `a`
- `10@a` - выполнить макрос 10 раз

Работа с текстом в кавычках:

- `va"` - выделить всё вместе с кавычками
- `ci"` - заменить текст внутри кавычек

Смысл команд:

- `a` - `around`, взять объект вместе с границами
- `i` - `inside`, взять только внутреннюю часть

Пример:

```text
"hello world"
```

Если курсор внутри строки:

- `va"` выделит `"hello world"`
- `ci"` удалит `hello world` и сразу переведёт в режим вставки
