# Vim basics

Короткий порядок действий:

1. Открыть учебный файл: `vim TEST`
2. Перейти в normal mode: `Esc`
3. Двигаться: `h j k l`
4. Искать: `/word`
5. Копировать строку: `yy`
6. Удалять строку: `dd`
7. Вставлять: `p`
8. Отменять: `u`

Файлы:

- `01_navigation.md` - базовая навигация по тексту и файлу
- `02_editing.md` - копирование, удаление, вставка и undo
- `03_search_and_visual.md` - поиск и выделение
- `04_macros_and_text_objects.md` - макросы и работа с текстовыми объектами
- `05_settings.md` - минимальные полезные настройки

Практика:

- `TEST` - небольшой файл для тренировки команд
- `00_tutor_text.txt` - простой текст для первых упражнений

Важно:

- перед командами normal mode нажмите `Esc`
- `u` отменяет последнее действие
- `Ctrl+r` возвращает отменённое действие
